# UI references

This project remains a Streamlit application. The following free 21st.dev components informed its visual treatment; their React code was not added because it would create a second frontend stack.

- [Dashboard Sidebar by Arun J Dass](https://dev.21st.dev/%40arunjdass/components/dashboard-sidebar): charcoal workspace shell, restrained contrast, compact navigation. Community component, free account access.
- [Sidebar by wensity](https://docs.21st.dev/%40wensity/components/sidebar): dark surface and subtle dividers. MIT license.
- [Minimal Button by jay sharma](https://preview.21st.dev/%40radiumcoders/components/minimal-button): quiet button hierarchy and simple hover feedback. MIT license.
- [Input by ReUI](https://docs.21st.dev/%40sean0205/components/input): compact fields with clear focus states. MIT license.

The result uses native Streamlit controls so form submission, search, download, and keyboard navigation continue to work without JavaScript bundles or animation libraries. The look also draws on the dark workbench layout described in [Command Code Desktop documentation](https://commandcode.ai/docs/desktop).
